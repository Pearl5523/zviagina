КОНДИТЕРСКАЯ «ЗВЯГИНА» — ПОДКЛЮЧЕНИЕ TELEGRAM

1. Установи Python с https://www.python.org/downloads/ (при установке Windows включи Add Python to PATH).
2. В папке проекта открой терминал (Shift + правая кнопка мыши в папке → открыть терминал).
3. Выполни:
   py -m pip install -r requirements.txt
4. Скопируй файл .env.example и назови копию .env
   В .env замени обе подсказки:
   TELEGRAM_BOT_TOKEN — на НОВЫЙ токен от BotFather (не присылай его никому).
   TELEGRAM_CHAT_ID — на числовой ID из @userinfobot.
5. В Telegram открой своего бота и нажми Start, чтобы бот мог написать тебе.
6. В терминале выполни:
   py server.py
7. Открой в браузере:
   http://127.0.0.1:5000
8. Заполни форму тестовыми данными и отправь её. Заявка должна прийти в Telegram.

Важно:
- Не открывай index.html двойным щелчком. Открывай сайт по адресу http://127.0.0.1:5000, пока сервер работает.
- Не отправляй файл .env и токен другим людям.
- Этот сервер доступен только на твоём компьютере. Чтобы принимать заявки через интернет, потребуется разместить сервер и сайт онлайн.
